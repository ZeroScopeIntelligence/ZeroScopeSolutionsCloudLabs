## Lab Workflow
1. Review the objective and prerequisites.
2. Use a dedicated non-production organization and project.
3. Prepare test identities and Google Groups.
4. Grant only required roles at the narrowest practical scope.
5. Test allowed and denied actions using non-administrator identities.
6. Remove temporary access and resources.

## Security Rules
- Do not use primary administrator identities for routine tests.
- Enable MFA for privileged accounts.
- Never commit passwords, keys, tokens, or recovery codes.
- Avoid broad Owner and Editor roles.
- Review costs before creating billable resources.
- Use only accounts and environments you are authorized to manage.
