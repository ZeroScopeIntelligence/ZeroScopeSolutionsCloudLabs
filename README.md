# Microsoft Azure Labs

Hands-on learning and practical exercises for **Microsoft Azure** as part of the ZeroScope Solutions Cloud Labs repository.

## Learning Objectives

- Understand cloud concepts, regions, zones, and the shared responsibility model.
- Deploy and manage compute and storage resources.
- Design cloud networks and control traffic.
- Configure identity, roles, and least-privilege access.
- Apply security, monitoring, and logging practices.
- Explore automation and Infrastructure as Code.
- Document practical projects and lessons learned.

## Lab Workflow

1. Read the lab objective and prerequisites.
2. Review the provider's official documentation.
3. Build the environment using an authorized account.
4. Validate the configuration and record the results.
5. Clean up resources when finished.
6. Document lessons learned and any issues encountered.

## Getting Started

Start with [Fundamentals](./Fundamentals/README.md), then work through the categories at your own pace. Use the [lab template](./LAB-TEMPLATE.md) to document new exercises and [notes](./NOTES.md) to keep reference material.

## Cost and Security

- Review pricing and estimated costs before creating resources.
- Use least-privilege permissions and secure authentication.
- Never commit credentials, private keys, tokens, or other secrets.
- Use only accounts and environments you are authorized to access.
- Delete or stop resources when they are no longer needed.
